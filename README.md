# 【S.004】Starryear-Monet-Stamp丨星年·莫奈印章

星年莫奈印章：将一张真实旅行照片重构为三种视觉状态——摄影证据、符号印记与莫奈式记忆。

**EVIDENCE → IMPRINT → MONET MEMORY**

## 使用

1. 上传一张你拥有合法权利的照片。
2. 最好同时告诉 AI 照片的地点或景点名称，尤其是小众场景。
3. 下载并使用 [`Starryear-Monet-Stamp-完整口令.txt`](./Starryear-Monet-Stamp-完整口令.txt)，或安装 [`Starryear-Monet-Stamp-Skill.zip`](./Starryear-Monet-Stamp-Skill.zip)。
