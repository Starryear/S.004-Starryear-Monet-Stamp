================================================================================
Using the photograph uploaded in this turn as the PRIMARY AND SOLE VISUAL EVIDENCE, create one finished vertical 2:3 travel-archive artwork titled:
Starryear-Monet-Stamp
The artwork must reconstruct one photographed place through three fundamentally different visual states:
TOP — PHOTOGRAPHIC EVIDENCE MIDDLE — SYMBOLIC IMPRINT BOTTOM — MONET MEMORY
This is NOT a fixed visual template.
Every photograph must generate its own:
visual language, symbol, palette, structural rhythm, spatial reconstruction, typographic hierarchy, information field, scene title, and postal stamp.
The fixed element is the METHOD, not the visual appearance.

CORE WORKFLOW
READ THE PHOTOGRAPH → CHECK WHETHER THE USER PROVIDED THE LOCATION → IF PROVIDED, LOCK THE USER-PROVIDED IDENTITY → IF NOT PROVIDED, IDENTIFY THE SCENE AS ACCURATELY AS POSSIBLE → VERIFY THE HIGHEST RELIABLE GEOGRAPHIC LEVEL → IF GEOGRAPHY REMAINS UNCERTAIN, NAME THE OBSERVABLE SCENE INSTEAD → ANALYZE THE PHOTOGRAPH → EXTRACT VISUAL DNA → EXTRACT COLOR DNA → PRESERVE REALITY → COMPRESS FORM → RECONSTRUCT MEMORY → RENDER THE FINAL ENGLISH ARCHIVAL INFORMATION.

0. ABSOLUTE LOCATION AND SCENE-IDENTITY RULE
LOCATION ACCURACY HAS HIGHER PRIORITY THAN DESIGN COMPLETENESS.
However:
THE FINAL ARTWORK SHOULD STILL CONTAIN A MEANINGFUL SCENE IDENTITY.
The model must therefore distinguish between:
A — USER-PROVIDED LOCATION
The user explicitly provides a:
country, province, city, district, landmark, park, lake, station, building, street, temple, garden, scenic area, or other place name.
This information has the highest priority.
Unless the photograph obviously contradicts it, use the user's supplied place identity exactly.
If the user says:
Ningbo Moon Lake
do not replace it with:
Hangzhou West Lake, Suzhou, another Chinese lake, or another visually similar famous destination.

B — VERIFIED LOCATION
The user did not provide a place name, but the photograph contains sufficiently reliable evidence.
Examples:
clearly readable signs, station names, building names, park plaques, road signs, official inscriptions, unique landmark structures, or multiple independent structural clues.
Only the geographic level actually supported by evidence may be used.

C — PLAUSIBLE LOCATION
The photograph visually resembles a known place, but the evidence is insufficient.
Examples:
“looks like West Lake”
“resembles Kyoto”
“probably Suzhou”
“possibly Shanghai”
“feels like a Japanese garden”
These are NOT verified geographic identities.
Do not present them as facts.

D — UNVERIFIED LOCATION
No reliable geographic location can be established.
In this case:
DO NOT INVENT A PLACE NAME.
Instead, identify and write the observable scene itself.
For example:
WATERSIDE GARDEN SCENE
URBAN RIVERSIDE WALK
LAKESIDE BOAT SCENE
TREE-LINED WATERFRONT
HISTORIC-STYLE GARDEN SCENE
MOUNTAIN ROAD STUDY
COASTAL STATION SCENE
TEMPLE COURTYARD STUDY
SUMMER STREET OBSERVATION
RIVERSIDE ARCHITECTURAL STUDY
The scene title must describe what is visibly present, not where the model imagines it might be.
Therefore:
UNKNOWN LOCATION DOES NOT MEAN EMPTY TYPOGRAPHY.
It means:
USE A TRUTHFUL SCENE IDENTITY INSTEAD OF A FABRICATED GEOGRAPHIC IDENTITY.

1. USER-PROVIDED LOCATION OVERRIDES VISUAL GUESSING
In normal use, the user may provide the location or attraction name together with the photograph.
When this happens:
USE THE USER-PROVIDED LOCATION DIRECTLY.
Do not independently replace it with a more famous or visually similar place.
User-provided information should control:
the main location typography, English archival caption, bottom information panel, postmark wording, and geographic metadata.
Do not silently upgrade the place to a more specific location than the user supplied.
If the user supplies only:
NINGBO
do not invent:
Moon Lake.
If the user supplies:
NINGBO MOON LAKE
use:
MOON LAKE · NINGBO
where appropriate.

2. IF THE USER DOES NOT PROVIDE THE LOCATION
If no geographic information is supplied by the user, actively inspect the photograph.
Do not immediately switch to generic text.
First attempt to determine the actual place.
Use this priority:
readable geographic text
unmistakable official signage
highly distinctive landmark structure
several independent structural clues
broader city / region / country evidence
observable scene identity.
The model should make a real attempt to identify the scene.
However:
attempting identification does NOT authorize guessing.

3. DIRECT VISUAL EVIDENCE
Inspect:
signs, station names, road names, park names, building plaques, maps, logos, official inscriptions, transit symbols, route numbers, road markings, architectural signage, and other visible geographic text.
Readable text is strong evidence.
But:
DO NOT HALLUCINATE SMALL OR BLURRED TEXT.
If text is:
blurred, tiny, distorted, partially hidden, or unreadable,
treat it as unreadable.
Never mentally complete unclear lettering into a familiar destination.

4. VISUAL CANDIDATES ARE ONLY HYPOTHESES
When direct evidence is absent, several possible locations may be considered internally.
Compare:
architectural massing, roof geometry, tower placement, window rhythm, bridge structure, shoreline geometry, street layout, mountain relationship, vegetation, waterfront structure, adjacent buildings, rail infrastructure, road configuration, and skyline context.
Do not choose the most famous candidate simply because it resembles the photograph.
FAME IS NOT EVIDENCE.
STYLE IS NOT LOCATION EVIDENCE.
Traditional Chinese architecture does not automatically mean Hangzhou.
A classical garden does not automatically mean Suzhou.
A lake does not automatically mean West Lake.
Japanese architecture does not automatically mean Kyoto.
A European street does not automatically mean Paris.
A pagoda does not automatically prove a specific pagoda.

5. ANTI-CIRCULAR IDENTIFICATION RULE
A candidate generated by the model cannot later become evidence supporting itself.
Forbidden reasoning:
“This looks like West Lake.”
→ therefore Hangzhou is likely.
→ therefore this architecture probably belongs to West Lake.
→ therefore West Lake is verified.
This is circular reasoning.
It is prohibited.
The same applies to:
Kyoto, Suzhou, Beijing, Shanghai, Paris, Venice, or any famous destination.
Candidate generation and verification must remain separate.

6. LOCATION CONFIDENCE GATE
Before rendering any geographic name, internally classify the result:
LEVEL A — USER CONFIRMED
Explicitly supplied by the user.
→ USE IT.
LEVEL B — HIGH-CONFIDENCE VERIFIED
Supported by direct geographic evidence or multiple independent distinctive clues.
→ USE ONLY THE VERIFIED LEVEL.
LEVEL C — PLAUSIBLE BUT UNVERIFIED
Possible, but not sufficiently proven.
→ DO NOT PRESENT THE LOCATION AS FACT.
Use an observable English scene title instead.
LEVEL D — UNKNOWN
No reliable geographic identity.
→ DO NOT INVENT A LOCATION.
Use an observable English scene title.

7. GEOGRAPHIC PRECISION LIMIT
Never render greater specificity than the evidence supports.
If only the country is known:
USE ONLY THE COUNTRY.
If only the city is verified:
USE ONLY THE CITY.
If the city is known but the landmark is uncertain:
DO NOT INVENT THE LANDMARK.
If neither city nor landmark is reliable:
USE A SCENE TITLE.
Broader but accurate is preferable to specific but wrong.

The overall work should feel like an unknown East Asian travel document discovered inside an archive drawer.
Use warm matte ivory or naturally aged paper wherever exposed.

Distress should concentrate around:

Avoid:

12. TOP — PHOTOGRAPHIC EVIDENCE
The upper section is the only section allowed to preserve the original photographic viewpoint.
Preserve the uploaded photograph faithfully:
architecture, people, animals, boats, vehicles, vegetation, water, skyline, lighting, perspective, object placement, and spatial relationships.
Do not reconstruct the architecture.
Do not replace subjects.
Do not add famous landmarks.
Do not remove major subjects.
Do not dramatically recolor the photograph.
The image must remain clearly photographic.
Only restrained archival reproduction is allowed:
slightly faded print density, softened blacks, extremely fine halftone, fine film grain, minor pigment fading, tiny scratches, subtle edge oxidation, and uneven ink absorption.
The original color relationships must remain recognizable.
NOT cinematic.

13. MIDDLE — SYMBOLIC IMPRINT
The middle section must compress the photograph rather than illustrate it.
Think:
archaeological imprint, primitive woodblock, experimental letterpress, damaged railway seal, museum specimen mark, travel insignia, fragmented regional printing block, or visual-memory symbol.
But never use a fixed template.
Identify the strongest structural motif in the photograph.
Possible source motifs:
roof curves, arches, windows, columns, boats, bridge geometry, tree trunks, mountain contours, water reflections, railings, umbrellas, street lamps, stairs, waves, vehicles, shadows, flowers, vertical poles, repeated hulls, or another scene-specific element.
Select only approximately 2–4 structural relationships.
Then:
DESTROY THE ORIGINAL PERSPECTIVE.
Do not draw the entire scene.
Do not make a miniature version of the top photograph.
Do not simply trace subjects.
Transform objects into graphic relationships.
Examples:
repeated arches → broken apertures
roof peaks → displaced wedges
tree trunks → thin vertical cuts
water → fragmented reflection bands
tower → one interrupted vertical form
windows → incomplete openings
birds → tiny directional marks
bridge → incomplete arc
flowers → irregular pigment clusters
boat canopies → flattened floating arcs
boat supports → interrupted vertical marks
The imprint must remain connected to this photograph without reproducing its original composition.

18. BOTTOM — MONET MEMORY
The bottom section must undergo the strongest transformation.
This is the defining characteristic of:
Starryear-Monet-Stamp.
The bottom is not:
the original photograph with an oil-paint filter,
the photograph with scratches,
a newspaper overlay,
or a dirty vintage collage.
Instead:
DISASSEMBLE THE PHOTOGRAPH AND REBUILD THE PLACE AS A PAINTERLY MEMORY.
Some forms remain.
Some colors survive.
Some distances collapse.
Some objects shift.
Some reflections detach.
Architecture becomes incomplete.
Minor details disappear.
Create a genuinely new composition.
Do not preserve the original framing.
Do not preserve the original object placement.
Do not preserve the original photographic perspective.

19. MONET MEMORY RECONSTRUCTION METHOD
Select approximately 4–7 important source fragments.
Then reorganize them.
Possible operations include:
enlarge one important form,
aggressively crop another,
move an object,
separate a roof from its building,
repeat a silhouette as a displaced echo,
detach a reflection,
compress the background,
expand vegetation,
flatten depth,
overlap foreground and background,
remove secondary objects,
repeat one source rhythm,
or dissolve selected areas into paper.
The dominant visual subject must preserve its visual weight.
If the source photograph is dominated by:
one bridge, tower, temple, building, tree, boat group, vehicle group, flower field, gate, or another large visual mass,
the bottom must still preserve its importance.
But its:
position, scale, geometry, perspective, and relationship to surrounding objects
may change radically.
Use:
one dominant large-scale structure,
two to four medium-scale visual rhythms,
and a limited number of small directional marks.
Create:
a visual entry point,
a zone of concentration,
and a quieter breathing area.
Maintain asymmetry.

20. MONET-LIKE ATMOSPHERIC LANGUAGE
The bottom may use a restrained painterly language inspired by the perceptual logic of Impressionist landscape painting.
Use:
broken color, reflected light, soft atmospheric distance, controlled visible brushwork, selective edge loss, color vibration, luminous midtones, and broad painterly relationships.
A subtle Monet-like atmospheric sensibility is allowed.
However:
DO NOT COPY OR RECREATE ANY SPECIFIC MONET PAINTING.
Do not turn everything into heavy oil paint.
Do not cover the entire section with thick impasto.
Do not create muddy painterly sludge.
Do not make the result excessively romantic.
Painterly treatment should primarily affect:
sky, water, vegetation, reflections, atmosphere, and selected architectural surfaces.
Some structural fragments may remain sharper.
Others may dissolve.
The result should feel:
luminous, airy, breathable, perceptual, quiet, and reconstructed.

22. BOTTOM CLEANNESS CONTROL
The Monet Memory section must remain cleaner and lighter than a typical distressed collage.
Keep approximately 80–90% visually readable and breathable.
Texture should describe:
paper, paint, wood, stone, foliage, architecture, reflection, water, and printing.
Texture must never become the main subject.
Use selectively:
soft dry brush, thin lithographic grain, restrained halftone, exposed paper, small palette-knife interruptions, broken-print regions, light scraping, and limited torn edges.
Strictly avoid:
all-over grime, dirty gray veils, dense newspaper text, black soot, random scratches everywhere, muddy brown overlays, excessive collage debris, burned edges, heavy splatter, visual noise, and overprocessed vintage filters.
If the section looks dirty before atmospheric:
REMOVE DISTRESS.
If texture hides the source colors:
REMOVE TEXTURE.
If the painterly treatment becomes muddy:
RESTORE CLEAN MIDTONES, LIGHT, AND AIR.

31. THREE-LAYER DIFFERENTIATION TEST
Before completion, compare the three sections.
TOP — EVIDENCE
Does it still clearly read as photographic reality?
If not:
restore photographic fidelity.
MIDDLE — IMPRINT
Could the symbolic composition exist without reproducing the photographic perspective?
If not:
abstract it further.
Does the symbol come specifically from this photograph?
If not:
extract another motif.
BOTTOM — MONET MEMORY
Is the composition genuinely reconstructed?
If it still resembles the original photograph too closely:
move, enlarge, remove, overlap, detach, flatten, crop, repeat, and reorganize the visual fragments.
Does the main subject retain appropriate visual importance?
If not:
restore its visual weight without restoring the original perspective.
Do the colors remain recognizably source-derived?
If not:
re-extract the palette.
Does the result look dirty rather than luminous?
If yes:
remove approximately half of the distress.

32. CROSS-IMAGE VARIATION TEST

Their middle sections must not all contain:

Their bottom sections must not all become:
brown newspaper collages, dirty oil paintings, identical torn-paper arrangements, or the same landscape reconstruction.
Their postal marks must not all contain:
the same icon, the same text arrangement, or the same destination logic.
Every photograph must generate its own:
symbol, palette, spatial rhythm, scene name, Monet reconstruction, postmark icon, typographic hierarchy, and archive field.
Only the method remains fixed:
EVIDENCE → IMPRINT → MONET MEMORY

Immediately before rendering any geographic name, perform a second independent verification.
Ask internally:
Did the user explicitly provide this location?
If yes:
use it unless clearly contradicted.
If not, what direct evidence supports it?
Am I relying mainly on:
architectural style, general atmosphere, lake scenery, traditional roofs, vegetation, mountains, boats, or resemblance to a famous destination?
If yes:
the location is not verified.
Could this realistically be another:
park, lake, city, district, temple, garden, station, waterfront, or scenic area?
If yes:
reduce geographic specificity.
Do at least three independent distinctive structural clues support a landmark-level identification?
If not:
remove the landmark name.
Is the city independently verified?
If not:
remove the city name.
Is the country itself sufficiently supported?
If not:
remove the country.
Did an earlier candidate become “evidence” merely because the model repeated it?
If yes:
discard that reasoning.
Is a famous location being chosen mainly because the artwork feels more complete with a recognizable destination?
If yes:
remove it.
If the geographic name disappeared from memory, would the same identification still be made from the photograph alone?
If not:
use a scene-based title instead.
